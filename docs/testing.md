# PROMANGO — الاختبار

## الأوامر (من `apps/api`)
| الأمر | ما يفعله |
|---|---|
| `npm run verify` | typecheck ثم lint ثم الوحدة ثم E2E (يجب أن يمر كله قبل أي تسليم) |
| `npm test` | اختبارات وحدة (`src/**/*.spec.ts`) — بلا قاعدة بيانات، ثوانٍ |
| `npm run test:e2e` | E2E حقيقي: تطبيق NestJS كامل (`createApp`) + PostgreSQL فعلي |
| `npm run typecheck` / `npm run lint` | `tsc --noEmit` / `oxlint` |

## قاعدة الاختبار
- `TEST_DATABASE_URL` في `apps/api/.env` ويجب أن ينتهي اسم القاعدة بـ **`_test`**، ويختلف عن `DATABASE_URL`، وإلا يرفض `test/env.ts` التشغيل (حماية بيانات التطوير). `resetDb()` يرفض أيضًا أي قاعدة لا تنتهي بـ `_test`.
- `test/global-setup.ts` يطبّق الـ migrations على قاعدة الاختبار مرة واحدة. `test/setup-env.ts` يوجّه `DATABASE_URL` إليها قبل أي استيراد للتطبيق.
- ملفات E2E تعمل **تباعًا** (قاعدة مشتركة) وكل اختبار يبدأ بـ `resetDb()` (TRUNCATE للشركات والمحاولات مع CASCADE؛ التخصصات عامة وتبقى).
- لا محاكاة (mock) للقاعدة أو المصادقة أو الحراس. المستخدمون يُنشأون بـ `auth_set_password` كما في الإنتاج.
- `test/helpers`: `db.ts`، `factories.ts` (`createCompany`، `createUser`، `twoCompanyFixture` لعزل الشركات)، `app.ts` (`createTestApp`)، `auth.ts` (`loginAs`، `bearer`).
- وحدة اختبار فقط `ProbeModule` (في `guards.e2e-spec.ts`) تضيف 3 مسارات لاختبار الحراس الحقيقية قبل وجود مسارات عمل محمية.

# الواجهة (`apps/web`) — حالة 2026-11-15

## الأوامر (من `apps/web`)
| الأمر | ما يفعله |
|---|---|
| `npm run verify` | typecheck (3 ملفات إعداد) ثم lint ثم الوحدة ثم البناء — يجب أن يمر كله |
| `npm test` | vitest + jsdom: وحدة ومكوّنات (87 اختبارًا، 8 ملفات) |
| `npm run e2e` | Playwright على **API حقيقي** عبر وكيل Vite: مشروعان `desktop` (1280×800) و`mobile` (Pixel 7) |

ملفات typecheck: `tsconfig.app.json` (الكود)، `tsconfig.vitest.json` (الكود + الاختبارات مع أنواع Node)، `tsconfig.node.json` (إعدادات Vite/Playwright وملفات `e2e/`). فحص الأنواع القديم كان لا يفحص شيئًا (`files: []`)؛ صُحّح.

## تشغيل E2E
1. `service postgresql start` ثم شغّل الـ API على 3000 (`cd apps/api && npm run build && node dist/main.js`) على قاعدة التطوير المُهيّأة بـ `seed:dev`.
2. شغّل Vite (`npm run dev`) أو دع Playwright يشغّله.
3. مرّر كلمة مرور بيانات التطوير من البيئة فقط: `SEED_PASSWORD=… E2E_DATABASE_URL=… npm run e2e`. (`E2E_DATABASE_URL` اختياري: يصفّر `login_attempts` قبل الجولة ويرفض أي قاعدة لا تنتهي بـ `_dev`/`_test`. بدونه قد تظهر 429 إن كررت التشغيل خلال 15 دقيقة لأن الحد 30 فشلًا لكل IP.)
4. الاختبارات تنشئ مستخدمين حقيقيين (`e2e-*@alpha.test`) عبر `POST /users` لاختبار التغيير الإلزامي؛ تبقى في قاعدة التطوير فقط.

## ما تغطيه اختبارات الوحدة والمكوّنات (87)
- الهوية: قيم Figma (Cairo/Emerald/Forest/Canvas)، تباين WCAG AA محسوب، أحجام الشريط والزوايا.
- أمن المصدر: لا `v-html` ولا `innerHTML` في الكود، لا خصائص CSS فيزيائية (RTL)، `redirect` الخارجي مرفوض (`safeRedirect`).
- الحراس (`decideNavigation`): زائر، تغيير إلزامي، شركة موقوفة، أدوار.
- مخزن الجلسة: دخول، خروج، انتهاء، شركة موقوفة، رموز لا تُسرَّب.
- `LoginView` و`ChangePasswordView`: تحقق محلي، أخطاء الخادم مربوطة بالحقول، منع النقر المزدوج، 429 مع عدّاد، شبكة مقطوعة.
- المكوّنات: `TextField` (ربط الوسم والخطأ بقارئات الشاشة)، `StatusBadge` (أيقونة+نص)، `ErrorState` (ماذا/لماذا/كيف/رقم الطلب/إعادة المحاولة)، `ToastHost`، `AppModal` (حبس التركيز، Esc).
- `installSessionHooks`: انتهاء الجلسة، تعليق الشركة، إلزام التغيير، تجديد صامت.

## ما تغطيه E2E (39 ناجحًا، 5 مُتخطّاة لأنها خاصة بمنصة واحدة)
دخول ناجح/فاشل بلا كشف لوجود الحساب، حد المحاولات بعدّاد وزر معطّل، انقطاع الشبكة + إعادة المحاولة، الدخول بالأدوار الأربعة وعزل شركتي ألفا/بيتا، التغيير الإلزامي لمستخدم جديد حقيقي (المؤقتة تتوقف عن العمل)، إعادة التحميل مع تدوير رمز التحديث، رمز مفقود/تالف، الخروج يُبطل الرمز في الخادم، `redirect` خارجي مرفوض (3 صور)، 404 داخل القالب، RTL (الشريط على اليمين 232px)، درج الجوال (فتح/Esc/خلفية/بلا تمرير أفقي)، رابط التخطي بلوحة المفاتيح، ظهور مؤشر التركيز، كلمة المرور لا تُخزَّن في المتصفح.

## ما اكتشفته الاختبارات فعلًا (وأُصلح)
1. `ErrorState`: زر «إعادة المحاولة» لا يظهر أبدًا افتراضيًا — Vue يحوّل الخاصية المنطقية الغائبة إلى `false`. (وحدة)
2. زر «تسجيل الخروج» على الجوال بلا اسم لقارئات الشاشة بسبب `display:none` على النص؛ صار إخفاءً بصريًا يُبقي الاسم. (E2E جوال)
3. فحص الأنواع لم يكن يفحص شيئًا (انظر أعلاه).

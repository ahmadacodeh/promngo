## ج. قرارات تنتظر المالك (👤)
1. مستودع Git خاص (P1) — **الآن**.
2. تخزين رمز التحديث: sessionStorage مقابل httpOnly cookie (P9) — عند بدء J3.
3. أعمدة `priority`/`due_date` (T4) — قبل B2.
4. بنود التعارض في `phase-j-audit §2.1` (P12) — قبل J4.
5. ترقية Figma أو تصدير اللقطات (P2) — قبل J6.
6. الأسعار والعملة والضرائب للخطط (متطلبات §10-6) — قبل T3 (تبقى الخطط موسومة تجريبية دونه).
